NezhaEDR Security Architecture

NezhaEDR captures network telemetry and package installations on-device, evaluating events via an O(1) memory rule engine.

Captive Subnet Routing TUN VPN

Utilizes Android VpnService to establish a zero-log TUN interface. General traffic bypasses VPN completely for zero performance impact.

Package Installation Sensor

Monitors app sideloading via BroadcastReceiver and evaluates package names against compiled Regular Expression rulesets.

O(1) Memory Rule Engine

Uses dual-index memory HashSets for instant domain and IP lookups, evaluating network events in sub-millisecond speeds.

Local SQLite Privacy Storage

100% on-device SQLite database. Zero remote telemetry. Users maintain complete ownership to export or wipe data.

Ruleset Contribution Workflow

  1. Fork the NezhaEDRAndroid repository on GitHub.
  2. Create a branch off 'dev' matching naming conventions: feature/*, bugfix/*, chore/*, or ruleset/*.
  3. Add or edit YAML detection rules in the /rules directory.
  4. Run local unit tests to verify rule syntax and test cases: ./gradlew app:testDebugUnitTest
  5. Submit a Pull Request targeting the 'dev' branch. CI/CD will validate compliance automatically.
